 GENERÁTOR FREKVENCÍ & MEDITACE - NÁVOD K OFFLINE POUŽITÍ
===================================================================

Gratulujeme! Tato složka obsahuje kompletní, plně funkční aplikaci
Generátor Frekvencí & Meditace připravenou k použití zcela bez internetu.

JAK APLIKACI SPUSTIT:
---------------------
1. Systém Windows (Máte 3 jednoduché možnosti):
   A) Dvakrát klikněte na soubor "generator_frekvenci_offline.html"
      (Aplikace je 100% samostatná a otevře se přímo ve vašem prohlížeči).
   B) Dvakrát klikněte na soubor "Spustit_Aplikaci_Windows.bat"
      (Automaticky najde a otevře soubor ve výchozím prohlížeči).
   C) Dvakrát klikněte na soubor "Spustit_Pres_Lokalni_Server_Windows.bat"
      (Spustí vestavěný lehký lokální HTTP server na http://localhost:8080).

2. Systém macOS:
   - Dvakrát klikněte na soubor "generator_frekvenci_offline.html"
   - Nebo spusťte skript "Spustit_Aplikaci_Mac.command".

3. Systém Linux:
   - Dvakrát klikněte na soubor "generator_frekvenci_offline.html"
   - Nebo v terminálu spusťte "./Spustit_Aplikaci_Linux.sh".
